Verify a certificate offline

Every tScrub Certificate of Destruction carries a QR code that contains a signed code, not just a web link. This page checks that signature on your own device, so it works with no network connection at all. Scan the code with the camera, or paste it in.

If you enter it, the check also fails when the code belongs to a different certificate.

What a pass means — and what it does not

A pass means the code was issued by tScrub for that Certificate ID at that time, signed with the key whose fingerprint is printed below. It does not, on its own, prove which drives were erased: this page holds no database. To see what the certificate actually records, open the online record for the same Certificate ID (the link is offered after a pass) or scan the certificate's QR with a normal camera app while online.
